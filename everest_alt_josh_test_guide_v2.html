Step 1

Install Everest ALT in ChatGPT.

Josh only needs to install the plugin once. After Everest ALT is active in the conversation, he can talk normally without repeating the plugin name in every request.

1

Open ChatGPT

Sign in to the ChatGPT account that will be used for the test.

2

Open Plugins

Open the Plugins area from the ChatGPT sidebar or plugin controls.

3

Install Everest ALT

Search for Everest ALT, or use the direct plugin link Brian provides, then choose Install plugin.

About typing “@Everest ALT”: it is optional. You can use it once if you want to explicitly tell ChatGPT which plugin to invoke, but you do not need to add it to every request. Once Everest ALT is available in the conversation, just type your request naturally.
Step 2

Run a complete simulated gift purchase.

Use these prompts in order. Each one has a copy button.

1. Find available gifts
Show me all available simulated gifts under $60. Do not prepare or approve an order yet.
2. Optional: show gift photos
Show me the gift gallery for the simulated gifts under $60. Do not prepare or approve any orders.
3. Find a birthday gift
Find a simulated birthday gift under $40. Show me the available choices and prices. Do not place an order yet.
4. Choose one and prepare the order
Prepare a simulated birthday gift using the tea sampler, with a birthday card. Show me the total cost and ask for my approval before recording the order.
5. Give the recipient and card message
Josh — card message: "First attempt"
6. Approve after the summary appears
Approve the simulated order.
If the tea sampler is not one of the returned choices, replace “tea sampler” with whichever gift Josh wants to test.
Step 3

Confirm the test worked.

✓
Gift search worked

Everest ALT returned choices within the requested price range.

✓
Price was shown first

The gift and total were displayed before approval.

✓
Explicit approval was required

The order was not recorded automatically.

✓
Simulated order was recorded

The final confirmation made clear that this was a simulation.
